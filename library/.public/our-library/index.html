Dictionary
Dictionary
A dictionary, in the first dictionary's own words: colloquially, a canonical source of canonical definitions; semantically, a catalogue of definitions, and so the one entry of this book that is the book itself. Twelve words stand here, one chapter each, in the order of the alphabet: eight with the senses the first dictionary gave them, and four that stand so that their definitions have somewhere to go.

Subjective Reference
Subjective Reference
The least a library needs to bind: the book every other book here extends, the theme it registers, the masthead and the byline it draws from a cover, and the faces a cover, a synopsis and a table wear. Each chapter says what the tool is and the file beside it is the tool. Borrowed, to begin, from the binder's own test library, and rebuilt from here by sketches.
The Design
The Design
Sketches of how this library might look, each a page of HTML made from the bound print with its forms on a switch, photographed, and committed to nothing. A sketch asks a question of a page; the manual changes only when the librarian says a form is the one.
