The Book
What a book is here
Every book in this library extends the library's own, so what a book is here is decided once and a change to it reaches all of them. The book class is the layout: the masthead, the byline drawn from what the book's cover says, then the chapters. Its file is where the library's theme is registered, once, on the class every book extends. A cover's route opens at the top of the page; every other bookmark turns as the framework does.
The class stands beside this chapter as its code, borrowed on 2026-10-30 from the binder's own test library, whose manual the team wrote, and to be rebuilt from here by sketches rather than kept. The theme it registers is The Theme; the masthead and the byline it draws are The Masthead and the Byline.
The Theme
The values and the parts
A theme is a set of values, the font, the measure, the ink, the paper, the link, and the parts that use them: the page, the levels of a book, the labels, the links, the apparatus and the figures. The file beside this chapter is the one the book registers. It is the test library's theme as borrowed, a serif on warm paper, and it stands only until the sketches say what this library's own looks like.
The Masthead and the Byline
What a cover exposes
The running head names the library, the book and its table of contents, and the byline says who wrote the book, what it is about when the book is a subject's own, and what it is filed under, all read from the cover and nowhere else. Neither is written in a chapter; the book draws them above its chapters from what the cover says. A subject is a book made one by its About, so the four books filed under Mathematics resolve to the book that is about it, and that book's byline says so. The file beside this chapter is both, borrowed from the test library and pointed at this library's name.
The Faces
A cover, a synopsis, a table
A face is how a book's apparatus looks: the cover a book opens on, the synopsis beside it, the table of contents that answers for its chapters and, when the book is a subject, for what is filed under it. Each is a word of the package dressed here, and every book of this library wears these four from the file beside this chapter, borrowed from the test library until a sketch replaces them.
Developing the Library
The loop
A save shows on an open page in under a second; a bind is the gate at the end of a piece of work and never the way to look during one. The workbench beside this chapter is the loop: it serves the library live from its sources, keeps one browser open on it, and answers a look with what it found and a photograph. Borrowed from the librarian's own library on 2026-10-30, its built address this library's.
node library/.reference/5-developing-the-library~workbench.mjs, once, left open
node library/.reference/5-developing-the-library~workbench.mjs look the-team
the same with built for the site the last bind made, phone for a phone's width, close at the end
The bind and the site
In the binding beside the site, npm run bind binds every book and leaves the site under the base the configuration names, and npm run preview with its port serves what the bind left. The site is committed as it is bound, and what is published is what was committed.
cd library/.public/.binding
npm run bind
npm run preview -- --port 4343 --strictPort
